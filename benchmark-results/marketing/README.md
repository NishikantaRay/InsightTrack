# Social carousel

Marketing deck for LinkedIn / X / Instagram (1080x1080, 2x).

Generated by `scripts/benchmarking/make-marketing-slides.js` from the real
benchmark result JSON — every figure traces to a measurement.

The engineering/evidence deck lives in `../slides/`.

**Not included:** an "apps vs appsv2" performance comparison. Those two
directories run byte-identical code, so any difference between them is
measurement noise rather than a product finding. Slide 6 uses them for what
they actually demonstrate: reproducibility.
