# Contributing Guide

How to contribute to InsightTrack.

---

## Workflow
1. Fork and clone the repo
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make changes and add tests
4. Run all tests locally
5. Commit with clear messages
6. Open a pull request (PR)

## Code Style
- Follow ES module syntax
- Use Prettier and ESLint (see config files)
- Tailwind for CSS
- Keep functions/components small

## PR Review
- All PRs require review (see `docs/pr-review.md`)
- Use the checklist in `docs/code-review.md`
